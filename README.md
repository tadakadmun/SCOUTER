SCOUTER AI INSPECTOR — PHASE 1

เปิดกล้องแล้ว AI วิเคราะห์ต่อเนื่องอัตโนมัติ

ตรวจจับเบื้องต้น:
- คน / สัตว์
- รถและยานพาหนะ
- สิ่งของทั่วไปที่ COCO-SSD รองรับ
- สีโดยประมาณ
- ระยะใกล้/กลาง/ไกลแบบสัมพัทธ์จากขนาดในภาพ
- ทิศทางการเคลื่อนที่แบบสัมพัทธ์

WATER MODE เป็นโหมดเตรียมต่อยอด ไม่ได้อ้างว่าในรุ่นนี้วัด L/min จากภาพได้จริง

ข้อจำกัด:
- ขนาด น้ำหนัก ความเร็วจริง และระยะเป็นเมตร ต้องมีสเกล/Depth/GPS/เซ็นเซอร์หรือวิธีสอบเทียบ
- การจำแนกสีเป็นการประมาณจากภาพ
- ต้องใช้อินเทอร์เน็ตครั้งแรกเพื่อโหลด TensorFlow.js/COCO-SSD จาก CDN
- กล้องต้องเปิดผ่าน HTTPS หรือ localhost
- ฟรี ไม่มี paid AI API
