SCOUTER AI INSPECTOR V1.1 FIXED

แก้ปัญหาจาก V1:
- ต้องแตะ OPEN AI เพียงครั้งเดียวเพื่อขอสิทธิ์กล้อง
- หลังอนุญาตแล้ว AI วิเคราะห์ต่อเนื่อง ไม่ต้องกด SCAN
- แสดงสถานะ LOADING AI / LIVE AI / ERROR
- ถ้า CDN AI โหลดไม่ได้จะแจ้งสาเหตุ
- ลด threshold เป็น 0.35 เพื่อให้ตรวจจับวัตถุได้มากขึ้น
- แก้การคำนวณทิศทางให้ดูจากตำแหน่งเฟรมก่อนหน้า
- รองรับ iPhone/Safari ได้ดีขึ้น

หมายเหตุ: ต้องเปิดผ่าน HTTPS (GitHub Pages ใช้ได้) และต้องมีอินเทอร์เน็ตครั้งแรกเพื่อโหลดโมเดลจาก CDN


V1.2 UX FIX
- ตัวอักษร/ค่าผลตรวจใหญ่ขึ้น
- กรอบและชื่อวัตถุอ่านง่ายขึ้น
- ลดการกระพริบ/หายของผลตรวจ
- เก็บผลวัตถุที่เพิ่งพบไว้ประมาณ 1.8 วินาที
- วิเคราะห์ทุก ~260 ms เพื่อให้ข้อมูลไม่เปลี่ยนเร็วเกินไป
- เพิ่มความไวของ detector เป็น threshold 0.28
- รองรับหลายวัตถุในภาพมากขึ้น

V1.3 UI
- วัตถุแต่ละเป้าหมายมีสีประจำตัวไม่ซ้ำกันเท่าที่ palette รองรับ
- สีของกรอบ + ป้ายชื่อ + การ์ดรายละเอียดเป็นสีเดียวกัน
- มี Focus Panel ลอยบนภาพ แสดงรายละเอียดของวัตถุเด่นทันที ไม่ต้องเลื่อนลง
- รายการวัตถุด้านล่างเปลี่ยนเป็นการ์ด 2 คอลัมน์ ลดพื้นที่และลดการเลื่อน
