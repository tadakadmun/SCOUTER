# ผู้ช่วยเตือนขณะขับ

ระบบช่วยเตือนสำหรับติดหน้ารถ ทำงานในเบราว์เซอร์ทั้งหมด ไม่มีค่าใช้จ่าย ไม่ต้องสมัครอะไร
และไม่ส่งภาพออกจากเครื่อง

**ระบบนี้ไม่ได้ขับรถแทนคุณ** เป็นตัวช่วยเตือนที่พลาดได้และเตือนผิดได้
ผู้ขับต้องมองถนนและควบคุมรถเองตลอดเวลา

---

## ทำอะไรได้

ตัดของเล่นออกหมด เหลือสามอย่างที่ประเมินแล้วว่าทำได้จริงด้วยกล้องมือถือ

**1. เตือนชนท้าย**
วัดจากอัตราการขยายของวัตถุในภาพ ไม่ต้องรู้ระยะจริง ไม่ต้องรู้ขนาดจริง
เพราะความกว้างของวัตถุในภาพแปรผกผันกับระยะ ถ้าเข้าใกล้ด้วยความเร็วคงที่
ค่า 1/ความกว้าง จะเป็นเส้นตรงในเวลา ฟิตเส้นตรงแล้วหาจุดตัดแกน = เวลาก่อนชน
หลักการเดียวกับระบบเตือนชนท้ายในรถจริง เตือนเมื่อเหลือน้อยกว่า 2.8 วินาที
และเตือนระดับวิกฤตที่ 1.7 วินาที

**2. เตือนออกนอกเลน**
แปลงภาพเป็นมุมมองจากด้านบนก่อน แล้วจึงหาเส้นเลน
เพราะบนภาพปกติ เส้นเลนลู่เข้าหากันเสมอ ค่าการเบี่ยงจึงเปลี่ยนไปตามมุมก้มของโทรศัพท์
พอแปลงเป็นมุมบนแล้ว เส้นกลายเป็นเส้นขนาน วัดออกมาเป็นเมตรได้จริง
เตือนเมื่อรถเบี่ยงเกิน 72% ของครึ่งเลน ค้างเกินครึ่งวินาที ที่ความเร็วเกิน 45 กม./ชม.

**3. เตือนความเร็วเกินและโค้งข้างหน้า**
ใช้ข้อมูลถนนจาก OpenStreetMap ผ่าน Overpass API (ใช้ฟรี ไม่ต้องมีคีย์)
คำนวณรัศมีความโค้งข้างหน้าแล้วเทียบกับความเร็วที่ยังปลอดภัยในโค้งนั้น
ข้อมูลถนนเป็นสิ่งที่รู้ล่วงหน้าได้และไม่พังเมื่อฝนตก จึงเตือนได้ก่อนกล้องเห็นเสมอ

นอกจากนั้นมี **ตัววัดว่ากล้องมองเห็นแค่ไหน** ซึ่งมีหน้าที่เดียวคือ
บอกว่าเมื่อไหร่ที่ไม่ควรเชื่อสองข้อแรก

## ไม่ทำอะไร

- ไม่มีลูกศรบอกทิศทางให้เลี้ยว — ลูกศรที่คำนวณจากภาพมีโอกาสชี้ผิด
  และคนขับที่เหลือบเห็นจะตีความว่าเป็นคำสั่ง อันตรายกว่าไม่มีอะไรเลย
- **ไม่บอกว่าแซงได้** ระบบนี้เตือนได้แต่อนุญาตไม่ได้
  การอ่านเส้นประผิดครั้งเดียวแล้วบอกให้แซง คือความเสียหายที่ย้อนคืนไม่ได้
  จึงรายงานเฉพาะเส้นทึบและเส้นเหลืองคู่ ส่วนเส้นประไม่พูดถึงเลย
- ไม่นำทางเลี้ยวซ้ายเลี้ยวขวา ให้ใช้แอปแผนที่ควบคู่ไป
- ไม่มีคะแนน ไม่มีตัวเลขที่ดูเท่แต่ไม่มีความหมาย

## หลักที่ยึดตลอดโค้ดชุดนี้

**เงียบดีกว่าผิด** ในระบบความปลอดภัย การเตือนพลาดครั้งเดียวทำให้ผู้ใช้ปิดระบบถาวร
แล้วมันก็ช่วยอะไรไม่ได้อีกเลย ทุกการเตือนจึงมีเงื่อนไขความเชื่อมั่น
ต้องเข้าเงื่อนไขติดกันหลายรอบ และมีระยะพักของตัวเอง

**ล้มเหลวต้องดัง** ระบบที่ตายเงียบอันตรายกว่าไม่ติดตั้ง เพราะคนขับยังเห็นจอเขียว
ทั้งที่ภาพค้างไปแล้ว จึงมีตัวเฝ้าระวังที่ประกาศ "ไม่พร้อม" ทันทีที่การตรวจจับหยุดเกิน 1.5 วินาที
กล้องหลุด หรือเครื่องร้อนจนประมวลผลไม่ทัน

**ข้อความเตือนไม่ใช่มาตรการควบคุม** พอ GPS บอกว่ารถวิ่งเกิน 5 กม./ชม.
ปุ่มทุกปุ่มถูกปิดจริงๆ ไม่ใช่แค่ขึ้นข้อความว่าห้ามแตะ

## เริ่มใช้งาน

ต้องเปิดผ่าน HTTPS หรือ localhost เท่านั้น ไม่งั้นเบราว์เซอร์ไม่ให้ใช้กล้อง

**วิธีฟรีที่ง่ายที่สุด — GitHub Pages**

1. อัปโหลดทุกไฟล์ขึ้น repository
2. Settings → Pages → เลือก branch แล้ว Save
3. เปิด URL ที่ได้บนมือถือ แล้วกด "เพิ่มไปยังหน้าจอโฮม"

ทดสอบในเครื่อง: `npm run serve` แล้วเปิด `http://localhost:8080`

**ครั้งแรกต้องมีอินเทอร์เน็ต** เพื่อโหลดโมเดล AI (~7 MB)
หลังจากนั้นโมเดลถูกเก็บใน IndexedDB และไฟล์แอปถูกเก็บใน Service Worker
เปิดใช้งานได้แม้ไม่มีสัญญาณ (ยกเว้นข้อมูลถนนจาก OpenStreetMap)

## ตั้งค่ากล้องก่อนใช้จริง

จอดรถในเลนตรง กด "ตั้งค่ากล้อง" แล้วเลื่อนให้

- เส้นประทับเส้นขอบฟ้า
- เส้นฟ้าสองเส้นทับขอบเลนซ้ายขวา
- เส้นเหลืองตรงกับกึ่งกลางฝากระโปรง

ไม่ตั้งค่าก็ใช้ได้ แต่การวัดการเบี่ยงออกนอกเลนจะคลาดเคลื่อน เพราะกล้องแทบไม่เคยอยู่กลางรถพอดี

## ทดสอบ

```
npm test
```

ทดสอบ 29 ข้อครอบคลุมคณิตศาสตร์การแปลงมุมมอง การคำนวณเวลาก่อนชน การแยกสีเส้น
ตัวตรวจเลนบนภาพถนนสังเคราะห์ และตัววัดทัศนวิสัย
กับอีกชุดที่จำลองสถานการณ์ชนท้ายห้าแบบ รวมถึงกรณีที่ **ต้องไม่เตือน**
(รถถอยห่าง รถจอดข้างทาง รถติด) ซึ่งสำคัญพอกับกรณีที่ต้องเตือน

## ข้อจำกัดที่ต้องรู้ก่อนใช้

| เรื่อง | ความจริง |
|---|---|
| ความถี่การตรวจจับ | ราว 4–5 ครั้ง/วินาที ที่ 100 กม./ชม. รถวิ่งได้ราว 6 เมตรระหว่างแต่ละครั้ง |
| กว่าจะได้ค่า TTC ครั้งแรก | ต้องเห็นวัตถุติดกันราว 0.6–1 วินาที |
| กลางคืน | ตรวจจับได้แย่ลงมาก โดยเฉพาะคนเดินถนนและจักรยานที่ไม่มีแสงสะท้อน |
| ฝนหนัก | น้ำบนกระจกทำให้ภาพเบลอ ระบบจะประกาศว่าทัศนวิสัยต่ำและหยุดเชื่อผลจากภาพ |
| ป้ายจำกัดความเร็ว | อ่านจากข้อมูล OpenStreetMap ไม่ใช่จากป้ายจริง อาจไม่ตรงหรือไม่มีข้อมูล |
| ระยะเป็นเมตร | ประมาณจากขนาดมาตรฐานของวัตถุ คลาดเคลื่อนได้ราว ±20% |
| ความร้อน | ใช้กล้องต่อเนื่องทำให้เครื่องร้อน ระบบจะลดคุณภาพลงเองเมื่อประมวลผลไม่ทัน |
| กฎหมาย | ต้องติดบนแท่นยึดที่มั่นคงและไม่บังการมองเห็น การถือโทรศัพท์ขณะขับผิดกฎหมาย |

โมเดลที่ใช้คือ COCO-SSD ซึ่งเป็นโมเดลตรวจจับวัตถุทั่วไป ไม่ได้ฝึกมาเพื่องานถนนโดยเฉพาะ
รู้จักรถ คน จักรยาน มอเตอร์ไซค์ รถบรรทุก แต่ไม่รู้จักหลุมถนน ป้ายจราจรไทย
หรือสัตว์ที่ข้ามถนน

## สิ่งที่ยังควรทำต่อ

เรียงตามผลกระทบ

1. **ทดสอบกับคลิปถนนไทยจริง** ที่มีคำเฉลย เพื่อวัดอัตราการเตือนผิดและเตือนพลาด
   ตอนนี้ทดสอบด้วยภาพสังเคราะห์ ซึ่งพิสูจน์ได้แค่ว่าคณิตศาสตร์ถูก ไม่ได้พิสูจน์ว่าใช้ได้จริง
   ชุดข้อมูลฟรีที่ใช้อ้างอิงได้: BDD100K, Cityscapes, Mapillary Vistas, CULane
2. **ย้ายการประมวลผลไป Web Worker + OffscreenCanvas** เพื่อไม่ให้หน้าจอกระตุก
3. **เปลี่ยนไป MediaPipe Tasks Vision หรือ YOLO11n บน WebGPU** เร็วกว่า 2–4 เท่า
   และตรวจวัตถุเล็กที่อยู่ไกลได้ดีกว่า
4. **เพิ่ม segmentation พื้นผิวถนน** เพื่อยืนยันแนวถนนตอนที่ไม่มีเส้นเลนให้เห็น
   ซึ่งเป็นสภาพถนนต่างจังหวัดส่วนใหญ่
5. **บันทึกเหตุการณ์เตือนลงเครื่อง** เพื่อให้ปรับเกณฑ์จากข้อมูลจริงแทนการเดา
6. **โหมดกลางคืนที่ดีกว่านี้** ตอนนี้แค่เปลี่ยนสีจอ ยังไม่ได้ปรับพารามิเตอร์การตรวจจับ

## โครงสร้างไฟล์

```
index.html         หน้าจอเดียว มองแวบเดียวได้คำตอบ
style.css          โทนหน้าปัดรถ พร้อมโหมดกลางคืนสีอำพัน
sw.js              แคชไฟล์แอปและไลบรารี เพื่อให้เปิดได้ตอนไม่มีสัญญาณ
js/
  main.js          ลูปหลักและการตัดสินใจว่าจะเตือนอะไรก่อน
  camera.js        เปิดกล้อง จับกรณีกล้องหลุด
  detector.js      ตรวจจับวัตถุ + เก็บโมเดลลง IndexedDB
  tracker.js       ติดตามวัตถุ คำนวณเวลาก่อนชน ตรรกะเตือนชนท้าย
  lane.js          แปลงเป็นมุมมองจากด้านบน หาเส้นเลน ตรรกะเตือนออกนอกเลน
  vision.js        วัดทัศนวิสัยแบบที่ auto-exposure รบกวนไม่ได้
  alerts.js        คิวคำเตือนตามลำดับความสำคัญ เสียง การสั่น
  geo.js           GPS ความเร็ว ทิศทาง
  osm.js           ข้อมูลถนนจาก OpenStreetMap
  health.js        ตัวเฝ้าระวังตัวระบบเอง
  calibrate.js     ค่าติดตั้งกล้องและเรขาคณิตที่ตามมา
  ui.js            การแสดงผลทั้งหมด
  util.js          คณิตศาสตร์ที่ใช้ร่วมกัน
test/              ชุดทดสอบ รันด้วย npm test
```
